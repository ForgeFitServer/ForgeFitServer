About Forge Fitness Server

Forge Fitness Server (FFS) is an open-source fitness tracking application built for privacy and self-hosting.

FFS provides a comprehensive solution for personal fitness tracking with no account requirements, no subscription fees, and no telemetry. All your training data stays on your own server.

The application features a guided workout flow, exercise library with body mapping, progress tracking, and support for 12 languages. It's a self-hosted web application.

Forge Fitness Server is distributed under the AGPL-3.0 license. This ensures that your training data is truly yours, the software remains open and inspectable, and improvements benefit the entire community.

Whether you're self-hosting on your own server or running it in the cloud, FFS puts you in control of your fitness data.

Principles

  • Your data is yours. Local-first, one-file backups, no lock-in — leaving Forge Fitness Server must always be one export away.
  • No telemetry, ever. If a feature needs analytics to justify itself, it doesn't ship.
  • Dependency-light. The backend is one Node file with a single dependency; the frontend is React, a router and a store. Small enough to actually audit.
  • Open source that stays open. AGPL-3.0, so every fork and every hosted version owes its code back to everyone.
